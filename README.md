# 🌱 Watch4Trees – Purpose-First Reforestation Platform

> **"Your attention = a cleaner planet"**  
> A purpose-driven platform turning rewarded video ads and partner gameplay into real-world, certified reforestation impact.

---

## 🌲 About the Project

**Watch4Trees** is an innovative *Watch & Play to Plant* platform where user engagement and corporate ESG marketing budgets fund verified tree-planting initiatives in partnership with certified ecological foundations (e.g., *Posadzimy.pl*, *One Tree Planted*, *Eden Reforestation*).

### 🌟 Core Pillars

- 🎬 **Watch-to-Plant:** Watch non-intrusive Rewarded Video ads and complete eco-knowledge verification quizzes.
- 🎮 **Play-to-Plant:** Engage with partner game offerwalls converting playtime into Water Drops.
- 🌳 **Virtual Forest & Eco-Passports:** Automatic conversion (10 Water Drops = 1 physical tree planted) with digital certificates containing GPS coordinates.
- 🛡️ **Open Impact Ledger:** 100% financial transparency with public quarterly reports and certified planting batches.

---

## 🛠️ Tech Stack & Architecture

- **Framework:** Angular 19 (Standalone Components, Signals, Native Control Flow `@if`, `@for`, `@defer`)
- **Styling:** SCSS, Eco Dark UI, Glassmorphism, GPU-accelerated 60/120 FPS micro-animations
- **Internationalization:** JSON-based i18n (PL 🇵🇱 / EN 🇬🇧)
- **Standards:** Strict DRY design tokens, Clean Architecture, Mobile-First Responsive Design

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/<your-username>/watch4trees.git

# Navigate to application directory
cd watch4trees/watch4trees-app

# Install dependencies
npm install

# Start local development server
npm start
# or
ng serve
```

The application will be available at `http://localhost:4200/`.
